# 2026-11-03 移植範囲

データの置き場所・入力先を変えず、4画面と取得・集計・判定をNext.jsで完結させる。既存GASは残す。

| 対象 | 実装 | 保持した動作 |
| --- | --- | --- |
| 直接読取 | sheets-reader / xlsx-reader | 同じスプシ・タブ。数値・空欄・エラー・数式の区別 |
| 名前・候補 | portal-data / 既存画面JS | NFKC・空白・ふりがな・同名候補・既存の対象外 |
| 帰属・重複除外 | source-aggregation | 読者ID指定→経路→確定LINE補完、最初の日時、メール/LINE識別子。同じ生徒の範囲で統合 |
| 実績 | portal-data | 移行前の値、収益、同名行合算、2026年以降の月・年・全期間 |
| 月報 | portal-data / report-core | 日本時間の前月・前々月、原文・実数、列不足/不正値/対象外と0の区別 |
| 月報ログ保存 | monthly-output / monthly-app | 現行v11の共有検査・15列・サーバー実績確認・保存直前再検査・重複防止・案内と再試行 |
| 管理者 | admin-service / state-store | 現行PWハッシュ・NGリスト、1時間セッション、5回/10分制限、競合・期限切れ・ログアウト・永続保存 |
| 限定LINEリンク | portal-data | 許可名、固定タブ・ヘッダー、複数・不正・数式の拒否 |
| PNG・コピー・ランキング | 既存画面JS | 月報、SNS用・内部用、全文コピー、既存のデザインと期間 |
| 自動再取得 | 月報・実績JS | 60秒/タブ復帰、選択・期間・入力途中の文章を保持 |
| 月列追加・累計更新 | sheet-maintenance | 現行と同じ当月列・D/E累計の更新計画。実行は別承認まで無効 |
| 朝夕リスト・収益・前月確定通知 | notifications/reports・legacy-renderers | 元のFlex、集計、順位・同順位、分割、0件・取得失敗の扱い |
| 面談予定通知 | notifications/interview-core・interview-flex | 元の2タブ・帰属・取消・重複と最新の種別合算方針。通知専用の対象外を管理画面と分離 |
| 定期起動・送信台帳 | notifications/service・api/jobs・notification-worker | JST、秘密認証、実行担当の切替、期間ごとの重複抑止、結果不明の保留 |
| 専用TOP5画像 | resultsの秘密キー分岐・top5-download | 元のPNG・自動ダウンロード・スマホ手動保存、秘密キーをサーバーだけで判定 |

既存GASの全ソース・URL・スプシ更新・LINE通知・トリガーと、独立したTOP5専用URLは維持する。Next.jsは同じ機能をGASを呼ばずに実行する。元スプシ・入力元・収益列・シート名を変更しない。NG設定と送信台帳は新旧で独立するため、本番配信は担当を切り替えるまで有効にしない。

単体テストは架空データで帰属・重複・月境界・異常系・認証・永続保存を確認する。ブラウザは架空データで操作・コピー・PNG・自動更新を確認する。実接続は `tools/check-native-connection.mjs` で実データをログへ出さず旧GASと比較する。本番ドメイン・実機スマホは別途受入する。

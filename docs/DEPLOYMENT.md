# 運営環境への配置

2026-11-03の本人指示で、スプシ直接接続・Next.jsのサーバー処理へ変更しました。稼働中の4画面はGASのURL・共有鍵を必要としません。既存GASは残します。

## 設定

1. Node.js 22以上とNext.jsのサーバー実行環境を用意する。静的HTMLだけのホスティングは不可。
2. ビルド時は `NEXT_PUBLIC_BASE_PATH=/aione-instagram`、実行時は `PORTAL_PUBLIC_ORIGIN=https://tools.aione.co.jp`。
3. `PORTAL_SOURCE_CONFIG_FILE` に同じスプシID・タブ名・名寄せ設定の私有JSONを絶対パスで指定する。安全な経路で別途受け渡し、Git・依頼文へ貼らない。
4. `PORTAL_NATIVE_START_MONTH` を移行開始月へ固定する。以降も値を現在月へ更新しない。以前の実績はスプシ、以降のリスト数は登録元データから計算する。収益は同じスプシの列を読む。
5. `api` 接続ではGoogle ADCと対象スプシの読取権限を用意する。`xlsx` 接続では既存のアクセス設定でエクスポートを取得できることを確認する。接続のために公開・共有設定を変更しない。
6. 現行PWハッシュを `PORTAL_ADMIN_PASSWORD_HASH` へ、移行したNG設定ストアを `PORTAL_STATE_FILE` の絶対パスへ設定する。PWの生値は保存しない。
7. 管理者ストアは公開領域外の**永続ボリューム**へ置く。現在の実装は1ホストのプロセス間ロック・atomic replaceを使う。複数ホスト・サーバーレス・一時領域にはそのまま配置せず、共有トランザクションストア用アダプターへ変更する。
8. `npm ci`、`npm test`、`npm run build`、`npm run start -- --port <割当ポート>`。標準は127.0.0.1待受けのため、リバースプロキシから転送する。
9. `/aione-instagram` 以下の画面・`/_next/`・`/legacy/`・`/api/` を同じアプリへ転送し、既存のアクセス制御をAPIにも適用する。
10. 本番ドメインで受入後に利用者の導線を切り替える。従来のGAS URLを残す。

2026-11-22追加: 月報ログ保存には、同じ保存先・許可主体の私有設定、出力専用永続ストア、Google Sheets書込・Driveメタデータ読取のADCが必要です。詳細は [MONTHLY_OUTPUT.md](MONTHLY_OUTPUT.md)。接続未設定時は保存を有効表示せず、コピー・オプチャ導線を維持します。共有権限は移植作業で変更しません。

## 受入

- 4画面の表示・移動と、ブラウザ/サーバーがGASを呼ばず同じスプシから読んでいること。
- 元の名寄せ・重複除外・同名合算・対象外・月/年/全期間が一致すること。
- スプシ更新を定期再取得で読め、選択・期間・月報の入力途中の文章が保持されること。標準の画面更新60秒・読取キャッシュ30秒と取得時間を考慮する。
- 月報の前月/前々月、NG文除外、全文コピー、月報と実績2種類の1080px画像保存が従来通り。
- 同じ管理者PW、期限・ログアウト・保存競合・再起動後の永続保存。旧GASのNG設定を変更しないこと。
- 取得失敗を0にしないこと。限定LINEリンクの固定列・不正値・複数・数式セルの扱い。
- 実機スマホ・LINE内ブラウザのコピーと画像保存。制限時の既存手動導線。

## 既存GASと定期処理

既存GASの画面・集計更新・LINE通知・トリガーは残します。Next.jsの表示・集計・管理者機能は独立しています。新しい通知やスプシ更新の定期実行は有効化していません。

月列追加・累計更新の実行元も移す場合は、まず `node --env-file=.env.local tools/native-maintenance.mjs` で書き込まない計画を確認します。別の本番切替承認とSheets APIの書込権限を用意してから、`--apply` を定期実行へ登録します。同じ元スプシへの旧GAS更新トリガーと重複させません。旧GAS自体の削除は不要です。

2026-11-12: TOP5専用画像・LINE通知・定期処理もNext.jsへ移植しました。Next.js版のTOP5は `/results?ranking_image=<PORTAL_TOP5_DOWNLOAD_KEY>`、配信の設定・起動・永続台帳・実行時刻は [NOTIFICATIONS.md](NOTIFICATIONS.md) を参照してください。旧GASは変更せず残し、新版の本番配信は無効です。コードのGitHub反映と、実際の配信担当の切替を区別します。
